# Development Rules

> **CRITICAL**: These rules apply to ALL coding work across every service.

## Test-Driven Development (TDD)

Always write tests **FIRST** before writing implementation code:

1. **Write failing tests** that define the expected behavior
2. **Write implementation code** to make the tests pass
3. **Refactor** while keeping tests green
